# TaxiPro 1.1.0 Release Notes

## English
- Improved route editing with a scrollable editor, visible map preview, and accessible save action.
- Added route calculation improvements, route alternatives, and cached Google Maps requests.
- Added ads, rewarded credits, Firebase Remote Config, and analytics plumbing.
- Expanded Premium, zone, history, export, statistics, and settings flows.
- Improved UI polish, filtering, charts, and ride/shift summaries.

## Bulgarian
- Подобрена редакция на маршрут със скролируем редактор, видима карта и достъпен бутон за запазване.
- Подобрено изчисляване на маршрути, алтернативни маршрути и кеширане на Google Maps заявки.
- Добавени реклами, кредити от rewarded ads, Firebase Remote Config и analytics основа.
- Разширени Premium, зони, история, експорт, статистики и настройки.
- Подобрени UI детайли, филтри, графики и обобщения за курсове/смени.
